Figure 3.7: Dual Authentication Flow Diagram

Verification Pipeline for Credential-Based (Argon2id) and Sui Wallet Cryptographic (Ed25519 + BLAKE2b) Sign-In

🔒 Select Authentication Pathway
Pathway A: Credential Auth SimpleJWT Engine
1. Client Credentials Entry
User submits Email address and Plaintext Password over TLS HTTPS connection.
2. User Account Lookup
Django Backend queries PostgreSQL database for matching `CustomUser` record by email.
3. Argon2id Hash Verification Argon2id
Computes memory-hard Argon2id key derivation check against stored `password` hash.
4. Active State & Role Guard
Validates `is_active` flag, loads user role (Farmer / Logistics / Admin), and prepares session payload.
Pathway B: Sui Wallet Sign-In Ed25519 Signature
1. Intent Message Construction
Frontend generates structured intent string: "Login to TerraNode with {sui_public_key}".
2. Wallet Private Key Signature Ed25519
User prompts Sui Wallet Extension (Slingshot/Mysten) to sign payload using Ed25519 private key.
3. Intent Prefix & Digest Calculation BLAKE2b
Backend prepends intent bytes [3, 0, 0] + ULEB128 length and computes 32-byte BLAKE2b hash.
4. PyNaCl Signature Verification PyNaCl
Verifies Ed25519 signature against registered `sui_public_key` using PyNaCl cryptographic library.

✅ Authentication Successful

User Identity & Role Permissions Verified — Session Tokens Issued

🔑 Access Token: SimpleJWT (15-Minute Expiration)
🔄 Refresh Token: Secure HTTP-Only Cookie (7-Day Expiration)
❌ Verification Failed: Return HTTP 401 Unauthorized / 429 Throttled
