Figure 3.1: TerraNode System Architecture
Integrated Blockchain-Anchored Smart Farm Management & Predictive Analytics Platform
Layer 1 User / Client Layer (Actors & Browser Extensions)
Farmer Web Client Actor
  • Telemetry Submission (Temp, Moisture, pH)
  • Produce Batch Minting Requests
  • Yield Forecast & Irrigation Queries
Logistics Web Client Actor
  • Batch Custody Transfer Requests
  • Shipment Status & Location Updates
  • Supply Chain Tracking Dashboard
Admin Web Client Actor
  • User Management & Role Assignment
  • System Audit Log Inspection
  • Infrastructure & Node Health Monitoring
Sui Wallet Extension Wallet
  • Ed25519 Keypair Management
  • Off-Chain Intent Signature Generation
  • Direct Sui BCS Transaction Signing
▼ HTTPS / DOM Interaction
▼ User Input & Telemetry Form Data
▼ Sui Wallet Window Provider API (dApp Kit)
Layer 2 Presentation Layer (Frontend — React 19 + TypeScript + Vite SPA)
AuthContext State
  • Manages JWT Access & Refresh Tokens
  • Sui Wallet Signature Auth State
  • User Role & Session Persistence
WalletContext Sui Web3
  • Mysten dApp Kit Integration
  • Sui JSON-RPC Provider Connection
  • Direct On-Chain Tx Execution & Signing
RoleGuard Router Routing
  • RBAC Route Protection (Farmer / Logistics / Admin)
  • Unauthorized Access Redirection
  • Dynamic Navigation & Layouts
Recharts Dashboard Data Vis
  • Telemetry Trends (Temp, Moisture, pH)
  • Yield Forecast Charts & Confidence Scores
  • Batch Lifecycle Progress Tracking
▼ REST / JSON API Requests (HTTPS)
▼ Bearer JWT Auth Header (Access Token)
⚡ Direct Sui RPC / BCS Tx Execution (Bypasses Backend for Minting/Transfer)
Layer 3 Business Logic Layer (Backend — Django 5.1 + DRF)
API Gateway & Auth Security
  • Simple JWT Token Handler
  • Argon2id Password Hashing
  • PyNaCl Ed25519 & BLAKE2b Verification
  • Rate Throttling (5 req/min)
Telemetry Module Core
  • Physical Range Validation (Temp/Moisture/pH)
  • Deterministic SHA-256 Digest Generator
  • Duplicate Reading Prevention
  • Farmer-linked FK Mapping
Ledger & Custody Lifecycle
  • 2-Step Lifecycle (Prepare → Confirm)
  • Maps Off-Chain Records to Sui Object IDs
  • Tracks On-Chain Tx Digests
  • Custody Status State Machine
Predictive Analytics AI/Engine
  • Weighted Moving Average Yield Forecast (Y)
  • Confidence Score Engine (C = min(0.95, n / 90))
  • Optimal Temp Deviation Penalty
  • Irrigation & Shading Recommendations
▼ Django ORM / SQL Queries
🔒 SHA-256 Hash Binding (Telemetry payload_sha256 ↔ Sui data_integrity_hash)
▼ Redis Cache Protocol (10m TTL)
▼ Sui JSON-RPC Event Syncing
Layer 4 Data Persistence & Ledger Layer (Database, Cache & Sui Blockchain)
PostgreSQL Database Relational DB
  • CustomUser: Credentials, Role, Sui Public Key
  • EnvironmentalTelemetry: Sensor Data & SHA-256 Hash
  • ProduceBatch: Off-chain Record, Sui Object ID, Status
  • AuditLog: Historical Actions & Security Logs
Redis Cache In-Memory
  • Caches Computed Yield Predictions
  • Time-To-Live (TTL): 600 seconds (10 mins)
  • Key Format: analytics:predict:{farmer_id}
  • Reduces PostgreSQL Query Load for Analytics
Sui Blockchain (Testnet) Layer-1 Ledger
  • Move Contract Package: terranode::produce_batch
  • ProduceBatch Objects with data_integrity_hash
  • Move Entry Functions: mint_batch, transfer_custody
  • Emitted Events: BatchMinted, CustodyTransferred
