Figure 3.3: Data Flow Diagram Level 1 (DFD Level 1)

Decomposition of TerraNode Core Subsystems, Data Transformation Processes, and Data Storage Layer

🌾 Farmer Client
Submits environmental telemetry, initiates produce batch minting, requests yield forecasts.
🚚 Logistics Handler
Executes custody transfers, updates transport milestones, tracks batch movement.
🛡️ System Administrator
Manages user RBAC permissions, monitors system audit logs and health telemetry.
⛓️ Sui Blockchain Network
Executes Move smart contracts, emits state events, guarantees tamper-proof ledger updates.
Process 1.0
Authentication & Identity Module
  • Validates Email / Password via Argon2id.
  • Verifies Ed25519 signatures via PyNaCl.
  • Issues signed Simple JWT Access/Refresh tokens.
Process 2.0
Telemetry Processing Module
  • Validates physiological ranges (Temp, Moisture, pH).
  • Computes deterministic SHA-256 digest.
  • Detects duplicates & logs immutable telemetry.
Process 3.0
Ledger & Custody Module
  • Executes 2-step batch lifecycle (Prepare $\rightarrow$ Confirm).
  • Coordinates Sui Move contract calls (`mint_batch`).
  • Maps off-chain records to Sui Object IDs & Tx Digests.
Process 4.0
Predictive Analytics Engine
  • Queries 90-day historical telemetry records.
  • Calculates Weighted Moving Average ($WMA$) yield forecasts.
  • Generates actionable irrigation & shading advice.
D1
PostgreSQL Relational Database
Stores User profiles, Argon2id hashes, Telemetry logs with SHA-256 digests, Produce Batch off-chain records, and Audit Logs.
D2
Redis Prediction Cache
In-memory key-value cache storing computed WMA yield predictions and confidence scores with 10-minute TTL.
D3
Sui Testnet Distributed Ledger
Layer-1 Sui Blockchain holding Move `ProduceBatch` shared objects with data integrity hash and custody owner fields.
