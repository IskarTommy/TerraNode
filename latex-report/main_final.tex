\chapter*{ABSTRACT}
\addcontentsline{toc}{chapter}{ABSTRACT}
\doublespacing

This project introduces TerraNode, a secure agricultural data management system that is built with a blockchain platform and supported by analytics. The platform tackles the major issues of data security, information transparency, and inaccurate predictive analytics in traditional, centralized agricultural information systems. TerraNode is a combination of a Django REST framework backend, a React-based web interface, and a backend of smart contracts implemented in Move programming language for the anchoring of all the agricultural records on the Sui blockchain. It collects environmental sensor information such as temperature, soil moisture, and soil pH readings, calculates the integrity hash of each record (SHA-256), and issues verifiable batch objects of produce on the Sui distributed ledger. The algorithm which reads into the historical telemetry data, uses a weighted moving average model to generate the yield predictions and includes computed confidence scores and variance indicators. The platform's UI is divided into farmer, logistics handler, and administrator interfaces, all of which have worker-based access control, JSON Web Token authentication, and Argon2id password hashing. The Sui blockchain part is verified with digital signatures based on Ed25519 and hashing of BLAKE2b, which are related to the wallet operations of login. Evaluation results show that 100\% of 143 automated test cases and 15 functional requirement verification scenarios have passed. On the Sui Testnet, the average latency for blockchain produce batch minting was 1.20 seconds, the average latency for custody transfer transactions was 0.90 seconds and the average gas execution cost was 0.003 SUI per transaction with deterministic transaction finality of less than 3.00 seconds. Moreover, the telemetry data integrity hashing was performed in 0.012ms, and the predictive analytics engine provided cached yield forecasts within 15ms (110ms when the forecast is not yet cached), creating a framework for agricultural management with high throughput and tamper proof capabilities to support smallholders.
